# SaySmile v2

Astro + GSAP site, hosted on GitHub Pages. Languages: Russian (default), Farsi, English.

```
npm install
npm run dev      # local preview
npm run build    # production build into dist/
```

- `src/styles/tokens.css` – color palette (light and dark)
- `src/scripts/animations.ts` – GSAP animation system (`data-reveal`, `data-reveal-group`, `data-parallax`)
- `src/config/site.ts` – contact details (fill in Telegram and email)
- `src/sections/` – one folder per section
